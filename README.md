# Retail Executive Dashboard | BlueMart

An interactive retail analytics dashboard designed to explore sales, profit, product performance, store performance, and inventory trends using BlueMart retail data.

## Project Overview

This project presents retail data in an executive-friendly dashboard. It helps users explore business performance across time, cities, stores, store types, product categories, subcategories, individual SKUs, and sales channels.

The reporting period covered by the dashboard is **January 2021 to October 2025**.

## Dashboard Highlights

- **Sales trends:** Explore how sales change over time.
- **Sales and profit analysis:** Compare performance across product categories.
- **Product performance:** Review profitable products and product-level performance.
- **City and store analysis:** Compare performance across locations and store types.
- **Channel analysis:** Explore sales performance by channel.
- **Inventory insights:** Review stock levels and reorder points to identify products that may need attention.
- **Interactive filters:** Filter by year, city, store type, store, category, subcategory, product SKU, and channel.
- **Management takeaways:** Present key observations in a format intended to support business discussions.

## Business Questions

This dashboard is designed to help explore questions such as:

1. How are sales changing over time?
2. Which categories and products contribute to sales and profit?
3. How does performance vary by city, store, and store type?
4. How do sales compare across channels?
5. Which products may need inventory or replenishment attention?
6. What additional context do profit and inventory provide beyond sales alone?

## How to Use

1. Download or clone this repository.
2. Open `Retail_Executive_Dashboard_v2.html` in a modern web browser.
3. Use the available filters to explore the dashboard.
4. Select **Reset Filters** to return to the default view, if needed.

No build step is required for the self-contained HTML dashboard.

## Data Notes

- The dashboard uses BlueMart sales, product, store, and inventory data for **January 2021 to October 2025**.
- The dashboard notes that **45 duplicate sales records are excluded**.
- Profit is defined in the dashboard as **sales minus product cost**.
- Review the dashboard's data definitions and filters when interpreting results.
